# ANTI-CIRCULARITY
Barred inferences (any appearing in a build = defect):
- implementation exists -> players experience X
- pattern observed -> DNA/identity exists
- model/agent agreement -> evidence
- self-audit passed -> ratified
Human outcomes are UNKNOWN until real playtest data exists. The evidence system CAPTURES, never
CONCLUDES. Forbidden fields (skill_score, was_optimal) never enter the evidence path.
