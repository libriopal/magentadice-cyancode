## 1 · The two halves, in one line each
- **magentadice-cyancode / FAR_NZY** = the **production organism**: a five-layer skill-dice game
  (L1 Sacred Core → L2 Energy Gate → L3 Modes → L4 Genre Meta → L5 Adornment), 20 genre modules,
  SOLO/VS/RALLY/HEIST, themes (Matter/Wave/Gem/Color), AGROS emotional music, a skill-sweepstakes economy.
- **glassbox-forest** = the **discovery greenhouse**: a D2 geometry + seeded branch generator + FOREST
  evidence ledger + Cohere advisory proposer. Closed-loop, provably fair, evidence-first.

**Merge thesis:** the greenhouse *discovers and evidences* experience-branches from real play; a branch
that real humans actually nourish **graduates** into the production organism as a genre module / mode /
theme — but only across explicit human gates. One shared **geometric positional cloud** (the D2 space,
extended) positions every concept from both halves, giving a single, testable identity.

automated push (anti-circularity + SOVEREIGNTY). L1 CyanCode is byte-identical on both sides so outcomes

## 5 · Quality points (identity-derived, measurable gates)

The cloud yields *quality points* — invariants + thresholds every position must satisfy, more realistic
than generic "definition of done" because they attach to where a thing sits in the identity:

- **Universal (every position):** L1 CyanCode byte-identical · deterministic (seeded PRNG only) ·
  provably fair (commit-reveal + public Verify) · **no forbidden fields** (skill_score/was_optimal) ·
  theme/adornment never touches scoring (L5 observes, never mutates).
- **Value axis > closed-loop:** RTP within tolerance (FAR_NZY Gates 2–5) · region/age gate ·
  **G1 + counsel** before any real value.
- **Mode = VS/HEIST (multiplayer):** symmetric-seed fairness · **G2** deploy · latency/no dropped-input
  (a dropped input is a legal violation, per magentadice governance).
- **Graduation (greenhouse → production):** a **real-play nutrient threshold** (human-set) + human
  ratification token + the relevant gate tokens. Synthetic/Cohere signal can never satisfy this.
- **Cohere/advisory anywhere:** budget-isolated, provenance=synthetic, non-ratifying, degrades without key.
