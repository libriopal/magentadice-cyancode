# GLASSBOX Forest — Overhaul Plan (approved parameters)

Reimagined ecosystem derived from the DevOS **D2** corpus + the GLASSBOX governance corpus.
This supersedes the phased `glassbox-labs/` build with a mature architecture built directly (no
P0/P1 re-derivation). `glassbox-labs/` stays intact as history.

## Approved decisions (human, this session)
- **Placement:** new parallel dir `glassbox-forest/` (glassbox-labs kept intact).
- **Experiment fidelity:** generate all branches as deterministic specs on a shared engine; seed a
  playable subset now; the rest are registered and become playable as real play nourishes them.
- **Growth authority (anti-circularity crux):** revive/grow vs. archive is driven **ONLY by real
  human play + reflection evidence**. The agent/generator/any simulation may propagate branches and
  tag provenance, but NEVER ranks "positive" branches and NEVER presents simulated fitness as observed.
- **Execution:** stage-gated — build a stage, present, wait for go.

## What "D2" means here (from the corpus)
- **D2 identity** = the game's identity as a **discovered region in a semantic design space** — stays
  DISCOVERED, never selected/optimized. Only real human play advances it.
- **geometrical memory** = the FOREST epoch ledger: per-branch lifecycle with **real/synthetic
  provenance** tagging; "never present simulated fitness as observed"; archive with code+seed.
- **branches of scope identity** = candidate directions sampled from the design-space axes.
- **D2 field** = the trait space (Discovery, Foresight, Mastery, Agency, Flow, Commitment, Tension,
  Recognition, Scarcity, Curiosity, Sovereignty).

## Five layers
```
L5 FOREST LEDGER (geometrical memory) — epoch lifecycle; real-evidence-only nourish/archive
L4 BRANCH GENERATOR                    — seeded, deterministic sampler over the D2 geometry
L3 D2 GEOMETRY                         — coordinate system {family × info-surface × substrate × traits}
L2 COMPOSABLE GAME ENGINE              — ported farkle-engine + commit-reveal + pluggable rule layers
L1 GOVERNANCE CORE                     — closed-loop Sparks, forbidden-field strip, gates, provenance
```

## The 25 new branches (+3 recreated current = 28)
A 5×5 grid the generator fills from a human-chosen seed:
- Families (competency lens): Foresight/Calibration · Intervention/Authoring · Shaping/Curation ·
  Transformation/Discovery · Commitment/Contestability.
- Information-surface variants: hidden · partial · full-read · authored · social-witness.
Recreated anchors: One-Roll, Keeper's Dilemma, Call Your Shot.

## Stages (each verified: tests green, type-check clean, build passes)
1. **Skeleton** — L3 geometry + L4 seeded generator + L5 FOREST ledger + governance carry. ← current
2. **Composable engine (L2)** — ported farkle-engine + rule layers; recreate the 3 current experiments.
3. **Catalog** — generate the 28-branch library from the chosen seed; seed the playable subset.
4. **Nutrient loop** — play+survey → FOREST ledger; nourish/archive from real evidence; ecosystem audit.
5. **Close** — ledger + STATE + audit artifact; push. Real-money/PvP/deploy/secrets/geo remain GATED.

## Guardrails (carried, non-negotiable)
Generation ≠ selection · closed-loop only · no forbidden fields (skill_score/was_optimal) · seeded PRNG
(no Math.random) · every branch reproducible from seed · HUMAN_GATES (G1–G5) remain structural and
uncrossed by this overhaul.
