# HUMAN GATES (structural sovereignty)
Consequential steps are blocked unless a human-created token exists at ratification/<GATE>.granted.
The agent CANNOT create these files. Even under auto-accept, the agent builds up to a gate and HALTS.

| Gate | Blocks | Token file | Human also provides |
|------|--------|-----------|----------------------|
| G1 | real-money / redemption / sweepstakes / stakes flow | ratification/G1_REAL_MONEY.granted | licensed-counsel sign-off |
| G2 | production deploy / public exposure | ratification/G2_DEPLOY.granted | target + rollback plan |
| G3 | secrets / real DB writes | ratification/G3_SECRETS.granted | scoped credentials |
| G4 | edit blocked_regions / value-model / geo-legal / KYC / age logic | ratification/G4_LEGAL_CONFIG.granted | the approved change |
| G5 | irreversible actions (data delete, force-push) | ratification/G5_IRREVERSIBLE.granted | explicit confirmation |

Token format (human writes): a file containing `GRANTED BY <name> ON <date> FOR <scope>`.
