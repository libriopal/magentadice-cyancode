# Scaffold Reference — magentadice-cyancode

Visual manifest pipeline file placement.
Run `./manifest.sh status` to verify at any time.

## Legend

```
✓  already exists (submodule or committed)
+  you create this (scaffold.sh handles it)
~  generated by Claude Code (not yet, expected)
⚙  prompt file you place manually
?  may or may not exist — check submodule init
```

## Correct Run Order

```bash
# 1. One-time setup
./manifest.sh scaffold /path/to/visual_manifest_schema.json

# 2. Check everything is wired correctly
./manifest.sh status

# 3. Check corpus is readable before handing to Claude Code
./manifest.sh corpus

# 4. Run the visual_overhaul.md prompt in Claude Code
#    Claude Code generates core/art/manifest/visual_manifest.json

# 5. Validate what Claude Code produced
./manifest.sh validate
```
